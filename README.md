# CELE Ambush Command Center

Offline-first, gamified **Civil Engineering Licensure Exam (CELE)** review Progressive Web App (PWA) for **iPadOS**, **iOS**, and desktop browsers.

- **Live Web App (Install on iPad / iPhone via Safari):** https://drl8490.github.io/cele-ambush/
- **Zero-Server Single-File Edition:** `CELE_Ambush_iOS_Standalone.html`

## Core Features

- **126 KIPPAP CELE Topics (`T-001` – `T-126`)**:
  - **MSTE** (47 topics, including 20 Home Turf nodes `T-028`–`T-047`)
  - **HPGE** (31 topics)
  - **PSAD** (48 topics)
- **14-Week Spiral War Plan & Daily 30-Minute Spiral Loop**:
  - Dual 15-minute drift-proof countdown timers (**Primary Target** + **7–14 Day Spiral Target**) with Wake Lock and background timestamp sync for iPad Split View alongside GoodNotes / Notability.
- **3-Stage Multi-Stage Unlock Engine (`±1%` Tolerance)**:
  - Stage 1: Governing equation / FBD condition
  - Stage 2: Intermediate calculation (`inputmode="decimal"` + one-tap `±` sign toggle for iPhone keypad)
  - Stage 3: Final numerical unlock
- **Tactical Rescue System**:
  - 100 Integrity XP per attempt (`-20 XP` Formula Hint, `-30 XP` Tactical Rescue pausing timers and launching Organic Chemistry Tutor, Khan Academy, or Gemini CELE Notebook).
- **126-Node Decay Matrix, Custom Puzzle Builder & JSON Sync**:
  - Tracks Locked, Active, Cleared, Decaying (`>7` days), and Spiral-Locked states in persistent `LocalStorage`, with native iOS/iPadOS Share Sheet JSON export/import.

## Install as a Standalone App on iPad & iPhone

1. Open **https://drl8490.github.io/cele-ambush/** in **Safari** on your iPad or iPhone.
2. Tap the **Share** button (`↑`).
3. Tap **Add to Home Screen** → **Add**.
4. Launch **CELE Ambush** from your Home Screen — runs full-screen and **100% offline in Airplane Mode**.
